# Chiller Anomaly Investigation SOP

**Document type:** SOP  
**Asset type:** chiller  
**Asset ID:** Chiller-03, M126  
**Version:** 1.0

## 1. Purpose

Standard operating procedure for investigating anomaly alerts generated by the LOF (Local Outlier Factor) model on Chiller-03. The model scores 197 engineered features every 30 minutes and flags readings that deviate from learned normal operation.

## 2. Anomaly Score Interpretation

| Field | Meaning |
|-------|---------|
| label = +1 | Normal operation |
| label = −1 | Anomaly flagged |
| decision_score > 0 | Normal (higher = more typical) |
| decision_score < 0 | Anomalous (more negative = stronger deviation) |

**Important:** The model detects *abnormal behavior*, not confirmed failure. Always verify with physical inspection and operating context before taking corrective action.

## 3. Pre-Investigation Checks

Before investigating root cause:

1. **Operational state:** Confirm RLA_Avg > 5% (chiller ON). Ignore alerts during OFF or startup transient (first 10 readings after OFF→ON).
2. **Data quality:** Verify OPC UA readings are current and not stale. Check for NaN or frozen values.
3. **Ambient context:** Note WET_BULB — elevated approach may be expected during high ambient humidity.
4. **Setpoint changes:** Confirm no recent CHW setpoint or schedule changes.

## 4. Investigation Workflow

### Step 4.1 — Review Primary Indicators

| Indicator | What to check |
|-----------|---------------|
| CHW delta-T | Below 8 °F at high RLA → low flow or bypass |
| CW delta-T | Below 6 °F or above 14 °F → condenser-side issue |
| CW approach to wet bulb | Above 14 °F → tower or flow problem |
| RLA spread | Phase imbalance across L1/L2/L3 |
| Tower tracking error | FEEDBACK vs SIGNAL divergence |
| Flow imbalance % | PH1 vs PH2 mismatch |

### Step 4.2 — Classify the Deviation

| Category | Typical signatures |
|----------|-------------------|
| Cooling performance | Elevated CW approach, high CW supply, normal RLA |
| Flow restriction | Low total flow, high flow imbalance |
| Tower control | Large tracking error, non-response flag |
| Electrical imbalance | High RLA spread, current imbalance |
| Transient / startup | readings_since_start < 10, recent OFF→ON |

### Step 4.3 — Field Verification

1. Verify condenser water flow at both headers.
2. Inspect cooling tower operation and basin condition.
3. Check chiller panel for active alarms.
4. Compare current readings to 7-day baseline trends (COP proxy, CW approach drift).

### Step 4.4 — Escalation Criteria

Escalate to senior maintenance or controls engineer if:

- Anomaly persists > 4 consecutive scoring intervals (2 hours)
- CW approach > 18 °F or CHW return > 8 °F above setpoint at high load
- Active chiller fault alarm concurrent with anomaly
- Insufficient data to determine root cause after field checks

## 5. Documentation

Record for each investigation:
- Timestamp and anomaly decision_score
- Operational state (OFF / TRANSIENT / STEADY)
- Key sensor values at time of alert
- Root cause (if identified) or "under investigation"
- Actions taken
